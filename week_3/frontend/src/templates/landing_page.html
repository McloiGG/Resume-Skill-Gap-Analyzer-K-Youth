Resume Skill Gap Analyzer

A containerized AI pipeline that compares resume text against job-market skills, visualizes the job database, and explains the highest-demand gaps through a local model.

Open Chat View Dashboard
Frontend
FastAPI, Bootstrap, PDF.js
Backend
FastAPI, Week 2 workflow
Model
Ollama, qwen3.5:4b
Orchestration
Docker Compose network
1

Extract Resume Text

The browser reads typed messages and PDF uploads, then sends clean text through the frontend proxy so Compose networking stays internal.

2

Find Skill Gaps

The backend calls the copied Week 2 workflow and compares resume skills against the SQLite job database to calculate demand-ranked gaps.

3

Explain Results

Ollama generates a concise explanation when available; deterministic gap data still returns if the local model or API key is missing.

Run the full system

Compose builds the frontend and backend images, starts Ollama, and puts the services on one private network so containers resolve each other by service name.

cd week_3
docker compose up --build

Open the frontend at http://127.0.0.1:8000. The backend health endpoint remains available at http://127.0.0.1:8001.
